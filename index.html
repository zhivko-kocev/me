Books, blogs and tools that help me out.

Fundamentals

  • On the Criteria To Be Used in Decomposing Systems into Modules — Parnas, 1972: split modules by the decisions they hide, not by the steps of the flow.
  • Modular Design — Ousterhout's lecture on deep modules and information hiding.
  • How do we tell truths that might hurt? — Dijkstra, 1975: uncomfortable truths about computing that still hold.
  • How to Write Unmaintainable Code — satire, do the opposite of it.
  • Rute User's Tutorial and Exposition — computers and Linux from scratch.
  • The TTY demystified — how the Unix terminal really works: line discipline, sessions, job control, signals.
  • The Unix Tree — the source code of Research Unix and the early BSDs, to browse.
  • UNIX Magic poster, annotated — every item on the poster, explained.
  • The Little Book of C — a short, clear intro to C.
  • Book of the Runtime — .NET under the hood.
  • Visualizing Garbage Collection Algorithms — five GC strategies, animated.
  • From Bare Metal to Containers — the history and explanation of code execution environments.
  • The WorldWideWeb Project — the first web page ever.
  • Semicolony — how everything works.
  • .gitignore Isn't the Only Way To Ignore Files in Git — .git/info/exclude, a global excludes file and git check-ignore -v.
  • PostgreSQL for Everything — Postgres in place of Kafka, Redis, Elasticsearch, MongoDB and more.

Coding agents

  • We improved 15 LLMs at coding in one afternoon. Only the harness changed. — same models, a better edit format, a big jump.
  • The Harness Playbook — lessons from building omp's next harness: state, runtime, sessions.
  • You only need the frontier model for one single edit — hand a half-run session to a cheaper model instead of a plan.
  • Pi is the Last Harness — a bet that Pi becomes the last open agent harness anyone needs.
  • Advanced Context Engineering for Coding Agents — research, plan, implement, compacting on purpose, on a 300k-line Rust codebase.
  • Writing a good CLAUDE.md — keep it short, universal and written by hand.
  • Long-Context Isn't the Answer — a 1M context made instruction-following worse; isolate context with sub-agents.
  • Learn Harness Engineering — a course on environments, state and verification for coding agents.
  • tdd skill — Matt Pocock's red-green-refactor for agents, in vertical slices.
  • hallmark — an agent skill that builds and lints web pages so they don't look generated.
  • claude-code-best-practice — a big index of Claude Code features and workflows.
  • Tasks as code — keep agent tasks as Markdown in Git.
  • Agentic dev and Rust — Niko Matsakis on why Rust fits agentic coding.
  • Maybe We Shouldn't Be Reviewing All This Code — Rachel Laycock: code review does too many jobs; move most of them earlier.
  • Build Wide, Ship Narrow — build the feature on one branch, then ship it as small PRs.
